## What the model did right (keep it)
- **Correct reasoning once the right code is in the window.** In requests s6 it traced `hist[1:]`, found "R1.history = [R1]", and honoured "breaking change we'll have to wait on". In rich_3006 s12 it turned `param.default == param.empty` into `is` immediately. In 14986 s20 it said "Found it!" on `setup.openapi`.
- **Repairs worked.** Packed args such as `"P2\", \"92\", …"` were accepted (httpx s29). Escaped line breaks were fixed with a visible "note: turned the escaped line breaks \n into line breaks" (rich_3521 s31). Keep these repairs and keep showing their notes.
- **Navigation hints were followed.** The model used the member list ("To see a member, send ["P1", a, b]") correctly (15800, httpx). The twin and copy lines ("same definition in src/ahttpx/…", "make the same change here if it needs it") were correct and useful.
- **`R<n>` and `skip` were used sensibly.** The model went back for uncovered requirements and skipped places it had explored (rich_3006: 4 skips). `done` was never used, so it can go.
- **Test output was read correctly.** rich_3521 s33 reasoned correctly from the `test_divide_emoji` diff. The failure excerpts are worth keeping, with the fix in #13.
